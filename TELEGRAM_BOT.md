# Telegram-бот с отчётами Fantrax: инструкция с нуля

Бот показывает отчёты по кнопкам:

```
/start
├── 📅 Отчет по туру ─► Тур 1 … Тур N ─► 🏆 Лидер/Нелидер
│                                         ⭐ Лучшие футболисты
│                                         👑 Король скамейки
│                                         🔥 Супертопы
│                                         🆓 Свободные агенты
└── 🏆 Отчет по сезону ─► 🏅 Рекорды · 📊 Таблица менеджеров · 🌟 Сборная сезона
                          🔟 10 лучших выступлений · 🥇 Лучший перформанс менеджеров
```

## Как это устроено (коротко)

1. `fantrax_report.py` забирает данные с Fantrax и формирует отчёт.
2. `update_data.py` сохраняет отчёты в папку `data/` (`tour_1.md`, `tour_2.md`, …, `season.md`). **Эта папка и есть «хранилище»** - база данных не нужна.
3. `bot.py` работает постоянно, читает файлы из `data/` и отвечает на нажатия кнопок. К Fantrax бот не обращается, поэтому отвечает мгновенно.

Каждую неделю после тура вы запускаете одну команду `update_data.py` (или настраиваете автозапуск, см. шаг 8) - и бот показывает свежие данные.

## Шаг 1. Создайте бота в Telegram

1. Откройте Telegram и найдите бота **@BotFather** (с синей галочкой).
2. Нажмите **Start** и отправьте команду `/newbot`.
3. BotFather спросит **имя** бота (отображается в чате), например: `Fantrax Лига`.
4. Затем **username** - латиницей, обязательно заканчивается на `bot`, например: `my_fantrax_league_bot`. Если занято - придумайте другой.
5. BotFather пришлёт сообщение с **токеном** вида `1234567890:AAH...`. Это пароль от бота.

> ⚠️ **Токен - секрет.** Любой, кто его знает, управляет ботом. Не публикуйте его в чатах, скриншотах и **не сохраняйте в файлах репозитория/GitHub**. Если токен утёк: у @BotFather команда `/revoke` выпустит новый.

Необязательно, но удобно (тоже в @BotFather): `/setdescription` - описание, `/setuserpic` - картинка, `/setcommands` - отправьте `start - Открыть меню`.

## Шаг 2. Установите Python

Нужен Python 3.8 или новее. Проверка: откройте PowerShell и выполните `python --version`.

Если открылся Microsoft Store или ошибка - установите Python: `winget install Python.Python.3.12 --scope user`, закройте и снова откройте PowerShell. Дополнительных библиотек (`pip install`) **не нужно**.

## Шаг 3. Скачайте проект

```
git clone https://github.com/ha73r0fa11/fantrax.git
cd fantrax
```

(Без git: на странице репозитория **Code → Download ZIP** и распакуйте.)

## Шаг 4. Соберите данные

Первый раз нужно собрать все уже сыгранные туры. Например, сыграно 7 туров:

```
python update_data.py --all 7
```

Это занимает несколько минут (чем больше туров, тем дольше) - скрипт делает много запросов к Fantrax. После окончания в папке `data/` появятся `tour_1.md … tour_7.md` и `season.md`.

Дальше после каждого нового тура достаточно:

```
python update_data.py --tour 8
```

(обновится тур 8 и сезон; старые туры не пересчитываются).

## Шаг 5. Запустите бота

PowerShell:

```
$env:BOT_TOKEN = "ВАШ_ТОКЕН_ОТ_BOTFATHER"
python bot.py
```

Должно появиться «Бот запущен». Окно не закрывайте - пока скрипт работает, работает и бот. Остановка - `Ctrl+C`.

## Шаг 6. Проверьте

Откройте своего бота в Telegram (ссылка `t.me/<username>`), нажмите **Start**. Должны появиться кнопки «Отчет по туру» и «Отчет по сезону». Пройдите по меню. Кнопка «⬅️ Назад» возвращает на предыдущий экран.

## Шаг 7. Добавьте бота в чат лиги

1. Откройте группу лиги → **Добавить участника** → найдите бота по username.
2. Отправьте в группе `/start@my_fantrax_league_bot`.
3. Чтобы бота видели только свои - необязательная защита: узнайте свой id у бота **@userinfobot** и перед запуском задайте
   `$env:ALLOWED_IDS = "123456789,987654321"` (id пользователей или группы через запятую). Тогда остальные нажатия игнорируются.

> Если бот в группе не реагирует на `/start`, в @BotFather выполните `/setprivacy` → выберите бота → **Disable**, затем удалите бота из группы и добавьте заново.

## Шаг 8. Чтобы работало постоянно и обновлялось само

Пока выключен компьютер или закрыто окно - бот не отвечает. Варианты:

**A. Домашний компьютер (проще всего).** Запускайте `python bot.py`, когда нужно. Для автозапуска: **Планировщик заданий Windows → Создать задачу → Триггер «При входе в систему» → Действие «Запуск программы»**: программа `python.exe` (полный путь), аргументы `bot.py`, «Рабочая папка» - папка проекта. Токен задайте системной переменной: **Параметры → Система → О системе → Дополнительные параметры → Переменные среды → создать `BOT_TOKEN`**.

**B. Дешёвый сервер (VPS), работает 24/7.** Любой Linux-сервер за 3-5 $/мес (Hetzner, Timeweb, DigitalOcean и т.п.): установить `python3` и `git`, повторить шаги 3-5, запускать через `systemd` или `tmux`/`screen`. Нужен, если бот должен отвечать, когда ваш компьютер выключен.

**Автообновление данных.** Туры завершаются раз в неделю, поэтому проще обновлять вручную командой `update_data.py --tour N`. Для автоматики - тот же Планировщик (или `cron` на сервере) с командой `python update_data.py --tour N` в нужный день (номер тура придётся менять вручную; если нужно автоопределение последнего тура - это можно добавить отдельно).

## Как хранятся данные и что можно сломать

- Данные - обычные текстовые файлы в `data/`. Их можно открыть в блокноте. Удалили файл - этого тура в меню не будет, пересоберёте командой `update_data.py --tour N` (для тура N сезон считается как «туры 1..N»; чтобы сезон был актуальным, запускайте для самого свежего тура последним).
- Папка `data/` добавлена в `.gitignore` и в GitHub не попадает.
- Меню туров строится автоматически по найденным файлам `tour_N.md`.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| `Не задана переменная окружения BOT_TOKEN` | Задайте токен в том же окне PowerShell, где запускаете бота (шаг 5) |
| Бот молчит | Окно закрыто / скрипт остановлен; проверьте, что `python bot.py` работает и нет ошибок |
| `Ошибка API: 401 Unauthorized` | Неверный токен |
| В меню нет туров | Папка `data/` пуста - выполните шаг 4 |
| `STALE_CLIENT` или ошибка при `update_data.py` | Fantrax обновил сайт: нужно поправить `CLIENT_VERSION` в `fantrax_report.py` |
| Таблица «съехала» на телефоне | Таблицы широкие; на узком экране поверните телефон горизонтально |
| Бот не отвечает в группе | Отключите privacy mode (шаг 7) |
